# Git Notes

## 1. git init

Initializes a new Git repository.

Example:
`git init`

## 2. git clone

Creates a local copy of a remote repository.

Example:
`git clone <repository-url>`

## 3. git status

Shows the current state of the working directory.

Example:
`git status`

## 4. git add

Stages changes for the next commit.

Example:
`git add git-notes.md`

## 5. git commit

Saves staged changes in the repository history.

Example:
`git commit -m "Add Git notes"`

## 6. git push

Uploads local commits to a remote repository.

Example:
`git push origin main`

## 7. git pull

Fetches and integrates changes from a remote repository.

Example:
`git pull origin main`

## 8. git branch

Lists branches in the repository.

Example:
`git branch`

## 9. git switch

Switches to another branch.

Example:
`git switch main`

## 10. git log

Displays the commit history.

Example:
`git log --oneline`

## 11. git diff
Shows changes that have not been staged.

Example:
git diff

## 12. git restore
Discards unstaged changes to a tracked file.

Example:
git restore filename.txt

## 13. git fetch
Downloads information about remote changes without integrating them into your current branch.

Example:
git fetch origin

## 14. git merge
Integrates changes from another branch into your current branch.

Example:
git merge main

## 15. git remote -v
Displays the remote repositories configured for your project.

Example:
git remote -v
